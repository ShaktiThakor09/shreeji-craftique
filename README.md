# Shreeji Craftique — GitHub Pages Catalog

A responsive static catalog website made from the supplied Shreeji Craftique catalog images.

## Files
- `index.html` — complete website
- `style.css` — design and responsive layout
- `images/` — catalog pages

## Publish on GitHub Pages

1. Create/login to your GitHub account.
2. Click **New repository**.
3. Repository name: `shreeji-craftique`
4. Choose **Public**.
5. Create the repository.
6. Upload `index.html`, `style.css`, and the entire `images` folder.
7. Commit the files.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a little while. GitHub will show your live site URL.

## Updating catalog pages
Replace an image inside `images/` while keeping the same filename, then upload/commit the replacement to GitHub. The website will automatically use the new image.

## Custom domain
GitHub Pages also supports a custom domain later. The site itself is plain HTML/CSS/JS, so no hosting server or database is required.
